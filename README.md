# OTP Verification

A simple OTP verification project built using HTML, CSS and JavaScript.

## Features

- Generates a random 4-digit OTP
- Stores OTP using localStorage
- Allows users to enter OTP digit by digit
- Verifies the entered OTP
- Uses two HTML pages

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open `index.html` in a browser.
Click "Get OTP" and enter the OTP shown in the alert.
